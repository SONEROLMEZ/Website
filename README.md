# Website

A travel portfolio and personal brand site for Soner Olmez, built as a lightweight static HTML project.

## Purpose

This repository hosts a travel-focused portfolio website with sections for:
- a hero landing experience
- destination highlights
- journal / travel notes
- personal story
- contact and social links

## Running locally

Open `index.html` directly in a browser, or serve the folder with a small static server such as:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
